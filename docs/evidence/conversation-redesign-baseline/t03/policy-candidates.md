# baseline/T03 — policy candidate inventory

**Status:** Inventory only, 2026-10-18. No shipping values are selected. The detailed design requires an explicit, versioned `ConversationPolicy`, and product acceptance of measured latency/readability remains a later release gate.

The observed values below describe the current legacy path or the `baseline/T02` run. They are evidence for later tuning, not recommendations. `baseline/T02` measured the current configured provider at ordinary p95 4.362 seconds (n=20) and action p95 0.025 seconds (n=8); repair had no samples because the legacy runtime does not issue a repair generation.

## Frozen evaluation set

The 44 scenarios in [baseline-evaluation-v1.json](../../../../backend/tests/fixtures/conversation/baseline-evaluation-v1.json) use the `baseline/T02` configured provider/model digest and settings as their baseline snapshot. There are 22 scenario templates for each NPC. Each fixture has four player turns, an isolated named initial state, expected mechanical outcome, current-scope resource revisions, and explicit external/provider events where applicable.

The six language dimensions have separate 1–5 anchors and explicit turn-level denominators. The fixture defines no composite score. Human calibration remains pending: before release scoring, two reviewers independently score a shared subset, reconcile rubric disagreements, and record agreement. Automated judges remain supporting evidence only. These scenarios are frozen test inputs; they do not assert exact live-model wording or choose new game mechanics.

Coverage includes the Proposal §19 scenario classes: greeting plus substantive question, mixed emotion/practical request, unfamiliar personal phrasing, biography continuity, story challenge, negotiation topic shift and return, preference/report retraction, unsupported capability, hypothetical and quoted requests, repetition/frustration, world-state change, provider and repair failure, new-game and clear-chat stale response, multiple supported actions, exact-consent single transfer, precondition invalidation, and receipt recovery after delivery failure.
